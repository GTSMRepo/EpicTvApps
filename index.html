Grab your apps here.

A small, direct list of APKs you can install on any Fire TV Stick, Onn box, or other Android TV device using the Downloader app. No accounts, no store review, just the files.

1. Open Downloader

On your TV box, launch the Downloader app from the home screen or app drawer.

2. Enter this address

Type this page's URL into the Downloader address bar. your-username.github.io/your-repo

3. Pick an app & install

Use the remote to select "Download APK," then tap Install when it finishes.

Only install apps from sources you trust. Update the list by editing data/apps.json in this repository.
